# Skill Information

Get details about a specific skill:

```bash
cat ~/.claude/skills/<skill-name>/SKILL.md
```

Example - get Python skill info:

```bash
cat ~/.claude/skills/python/SKILL.md
```

## Available Skills Directory

```bash
ls ~/.claude/skills/
```

## Usage

Use `/skill <name>` to load a skill after viewing its information.
